# ERCOT large-load fixtures

These fixtures establish the initial PGRR 145, NPRR 1325, current-rule, market
notice, and form record shapes. They deliberately retain explicit
`pending_legal_review` markers on lineage edges. Provider-specific HTML and
binary fixtures test extraction separately.

The full legal gold set must add historical and replaced-in-place pairs,
withdrawn material, OCR damage, unexpected MIME types, and corrected notices
before production approval.
