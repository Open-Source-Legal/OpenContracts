- Declared `playwright` (`^1.52.0`, the same range as `@playwright/test`) as an explicit devDependency in `frontend/package.json`. `frontend/scripts/generate-brand-pngs.js:25` requires the bare `playwright` package, but it was only ever installed transitively through `@playwright/test` and `@playwright/experimental-ct-core`, so a repackaging of either would have broken the brand-asset script with `Cannot find module 'playwright'` (the same phantom-dependency failure `dotenv` hit when the `@graphql-codegen/cli` tree was removed). The new range is mapped onto the existing `playwright@1.56.1` entry in `frontend/yarn.lock`, so no second copy of `playwright` or `playwright-core` is installed.
