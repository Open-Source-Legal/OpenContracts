- Removed `@graphql-codegen/cli` from `frontend/package.json` devDependencies, together with the `@graphql-codegen/cli/yaml` resolution that existed only for it. The package had no codegen config, no script, and no import anywhere in the frontend; generated types live in `frontend/src/types/graphql-api.ts` and are maintained by hand. Dropping it prunes 1,635 lockfile lines and every `@graphql-tools/*` package (27 entries), including `@graphql-tools/executor-legacy-ws`, the dev-only transitive behind PR #2420's security bump and its Node 22.15+ engine requirement, so that whole chain can no longer generate Dependabot alerts.
- Declared `dotenv@^16.6.1` as an explicit devDependency. `frontend/scripts/env.js` (run by `yarn build` and `yarn start`) has always required it, but it was only ever installed transitively via `@graphql-tools/prisma-loader` inside the codegen tree, so removing `@graphql-codegen/cli` broke the build until the dependency was made explicit.
