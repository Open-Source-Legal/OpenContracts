- New deterministic (non-LLM) enrichment for CBP CROSS-style customs-ruling corpora: `opencontractserver/enrichment/services/customs_ruling_citation_service.py` detects HTS tariff codes (plain `HTS_CODE` annotations) and CBP ruling-number citations (`CorpusReference` rows, `reference_type=DOCUMENT`, resolved against sibling document titles in the same corpus) from each document's own parsed text. Reuses the existing `EnrichmentWriter`/`Candidate`/`Resolution` machinery for persistence (PDF token projection, annotation dedup, `DocumentRelationship` graph rollup) rather than reimplementing it. Runnable via `python manage.py enrich_customs_rulings --corpus-id <id>` (`opencontractserver/corpuses/management/commands/enrich_customs_rulings.py`). Validated at 100% precision/recall against a 96-document pilot against the source dataset's own golden-tested extraction.
