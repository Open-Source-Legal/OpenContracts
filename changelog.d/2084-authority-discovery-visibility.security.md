- Authority enrichment now enforces **document-level** visibility on every user-facing entry point. `EnrichmentService.discover`, `EnrichmentService.scan`, and `EnrichmentService.apply` (`opencontractserver/enrichment/services/enrichment_service.py`) load their document set through `_load(..., require_document_visibility=True)`, which routes via `CorpusDocumentService.get_corpus_documents_visible_to_user` (the `MIN(corpus, document)` semantic) instead of the corpus-as-gate loader. A user who can read a corpus but lacks READ on a private document inside it no longer has that document scanned by the LLM citation extractor / grammar tier, surfaced through `discover`'s `review_candidates` or `scan`'s verbatim `raw_text` samples, or — most importantly — persisted by `apply` into `Annotation` / `CorpusReference` / `DocumentRelationship` rows (the durable form of the leak). Regression tests for all three surfaces in `opencontractserver/tests/test_enrichment_llm_integration.py`.
