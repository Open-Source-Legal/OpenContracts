- Authority discovery now enforces **document-level** visibility. `EnrichmentService.discover` (`opencontractserver/enrichment/services/enrichment_service.py`) loads its document set through `_load(..., require_document_visibility=True)`, which routes via `CorpusDocumentService.get_corpus_documents_visible_to_user` (the `MIN(corpus, document)` semantic) instead of the corpus-as-gate loader. A user who can read a corpus but lacks READ on a private document inside it no longer has that document scanned by the LLM citation extractor or surfaced through `review_candidates`.
