- **Frontend: pdfjs-dist 4.10 → 6.5 using the legacy build** (`frontend/package.json`, `DocumentKnowledgeBase.tsx`, `useDocumentLoader.ts`, `PDF.tsx`, `NativeLinkLayer.tsx`, `playwright/index.tsx`): every pdf.js import now uses `pdfjs-dist/legacy/build/*` — the default 6.x build calls `Map.prototype.getOrInsertComputed` and silently never finishes `page.render()` on browsers without it (Chromium < 145), which left every page overlay (annotations, selection layer) unrendered. API changes absorbed: `getDocument({ url })` (bare strings no longer accepted), `page.render({ canvas, viewport })` (`canvas` is required), and `convertToViewportRectangle` (removed) replaced by two `convertToViewportPoint` calls in `NativeLinkLayer`.
