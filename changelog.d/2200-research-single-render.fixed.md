- **Deep research: report no longer renders twice, and cite spans stop quoting themselves** (closes #2200). Post-#2192/#2193 runs emitted the whole report inline with raw `<cite>` spans, then a stub `## Sources` line, then the entire report again in footnote form — because `finalize()` post-processed only `markdown_body` while the agent passed the full report as `executive_summary` too, and the summary was never cite-rendered. `ResearchReportService.finalize` (`opencontractserver/research/services/research_reports.py`) now composes ONE document (summary + body) and runs the citation pipeline over it exactly once, so a `<cite>` tag anywhere is rendered instead of leaking raw. Two new guards close the doubling: `_sanitize_agent_markdown` strips agent-authored `## Executive Summary` / `## Sources` scaffolding (the system owns both), and `_summary_duplicates_body` drops a summary that merely restates the body. Self-quoting spans — the successor of #2183's sentence doubling, where a span's inner text is a verbatim copy of the sentence it decorates — are collapsed to the new self-closing marker form by `_verify_cite_spans`, so the claim renders once with a trailing footnote. `<cite ids="1,2"/>` is now a first-class cite form (`_CITE_SPAN_RE`, `_render_citations`) and is what the system prompt tells the agent to prefer. A `COMPLETED` report can also no longer be silently blank: when nothing survives composition (a body that was only scaffolding or a fabricated link), `finalize` records a warning saying so rather than storing an empty document that looks like a successful run. Stripping an agent-authored Sources/References section is likewise no longer silent — `finalize` counts and warns, so a dropped section is visible and the count doubles as a signal for whether the prompt rule forbidding those headings is landing. Section stripping is nesting-aware: a subsection inside the scaffolding (`## Sources` -> `### By Document`) goes with it instead of ending the skip and leaking an orphaned subheading into the report. Heading detection is suspended inside fenced code blocks, so a `# Sources` comment in a quoted snippet is not mistaken for a scaffolding heading — which used to swallow the rest of the block and the prose after it, leaving an unterminated fence. A fence now closes only on its own character (a `~~~` line inside a backtick block is content, per CommonMark), so an unevenly-fenced body cannot leave heading detection suspended for the rest of the document and silently skip the scaffolding it was supposed to strip. Echo collapse is also no longer the one strip in this pipeline without a warning: the threshold is a ratio over the span's inner text, so a collapse below full coverage discards a small uncovered remainder along with the restatement, and `finalize` now counts and reports exactly those — an exact echo, the observed shape, loses nothing and stays silent.
