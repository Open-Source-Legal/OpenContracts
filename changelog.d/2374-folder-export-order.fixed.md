- `opencontractserver/utils/export_v2.py::package_corpus_folders` — folders are exported in `tree_ordering` (depth-first) instead of `order_by("id")`. The parent-ID lookup needs each parent visited before its children. ID order breaks that for a folder moved under a newer folder, which would export with `parent_id: None` and be re-imported at the corpus root. Before django-tree-queries 0.26 the tree ordering silently overrode `order_by("id")`, so the bug was latent. Regression test: `test_corpus_export_import_v2.py::TestV2ExportUtilities::test_package_corpus_folders_parent_created_after_child`.
