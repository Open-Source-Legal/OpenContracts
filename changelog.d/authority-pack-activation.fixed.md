- Authority packs persist versioned artifacts in application storage and atomically activate them with their database content. Running web and worker processes refresh providers, taxonomy and source-host trust automatically, including removals in a new version. API and command installs share administrator and charter-approval requirements; failed activation preserves the prior version and exposes its error. See `authority_pack_service.py`, `authority_pack_artifacts.py` and the migration guidance in `docs/guides/authoring-authority-packs.md`.
