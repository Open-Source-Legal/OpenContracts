- Added a **LiteParse** PDF ingestion engine (`opencontractserver/pipeline/parsers/liteparse_parser.py::LiteParseParser`, issue #2074). LiteParse ([run-llama/liteparse](https://github.com/run-llama/liteparse)) parses PDFs fully locally (PDFium, optional Tesseract OCR). The parser uses LiteParse's spatial line items for bounding boxes, maps them to word-level PAWLs tokens via pdfplumber, derives feature labels (Title / Section Header / Text Block) and a parent-child hierarchy from font sizes, and extracts embedded images — matching the core outputs of the Docling and LlamaParse engines. Select it with `PDF_PARSER=liteparse`; DOCX/PPTX fall back to Docling since LiteParse is PDF-only. Configuration via `LITEPARSE_*` settings in `config/settings/base.py`; optional dependency in `requirements/ingestors/liteparse.txt`. Docs: `docs/pipelines/liteparse_parser.md`.
